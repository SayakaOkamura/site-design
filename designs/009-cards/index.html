サービス 四本

サービス

  • 業務を効率化するだけでなく、「使う人」を中心に据えて再設計された業務システムを提供

    何をするか

    画面から作りません。まず、いまその仕事をしている人が何を見て何を決めているかを並べます。効率化だけを先に置くと、決めごとが人の頭の中に残ったまま、道具だけが新しくなります。

    進め方

    1. 使っている人のそばで、いまのやり方を見せてもらう
    2. 決めごとを一覧にする（誰が、何を見て、何を決めているか）
    3. 短い周期で動くものを出して、使いながら直す
    4. 手が離れる形に整えて渡す

    出てくるもの

    • 決めごとの一覧
    • 画面の試作
    • 動く仕組み

  • 経営判断や業務プロセスの高度化を目的に、企業の持つデータ資産を活用したAI導入を支援

    何をするか

    AI を入れる前に、何を決めるためのものかを決めます。「データがあるから使う」から始めると、出てきたものを誰も判断に使いません。決めたいことを一つに絞って、そこから逆に組みます。

    進め方

    1. 決めたいことを一つに絞る
    2. いま何を見て決めているかを書き出す
    3. 手元のデータで試して、判断に足りるか見る
    4. 判断の場（会議や日々の運用）に載せる

    出てくるもの

    • 判断の見取り図
    • 試した結果と、届かなかったところ
    • 運用の形

  • テクノロジーによる分業・協業の再定義を通じて、フラットかつ柔軟な組織体制を実現

    何をするか

    誰が何を決めていいかを組み替えます。道具が変わると、仕事の分け方も変わります。道具だけ新しくして分け方を据え置くと、承認の列がそのまま残ります。

    進め方

    1. 決定の流れをたどる（どこで止まっているか）
    2. 止まっている理由を、人ではなく置き場に探す
    3. 権限の置き場を組み替える
    4. しばらく一緒に回して、戻らないか見る

    出てくるもの

    • 決定の流れ図
    • 役割と権限の割り当て
    • 運用の取り決め

  • 都市部に偏在するデジタル機会を全国へと広げるため、地方企業・自治体に対するノーコードツールやクラウドAIの導入支援

    何をするか

    その場所で続けられる形にします。作って渡すのではなく、あとから自分たちで直せるものを置きます。直せないものは、作った側が離れた時点で止まります。

    進め方

    1. いま使っている道具と、続けられる範囲を見る
    2. ノーコードで小さく作って、すぐ触ってもらう
    3. 触れる人を増やす（作り方ではなく、直し方から）
    4. 手が離れる形にする

    出てくるもの

    • 動く仕組み
    • 直し方の手引き
    • 直せる人
