# 016：次のデザイン案

本人：「え？嫌また複数案作ればよくない？」
本人：「前の案は据え置きにしつつ、そこに次のページみたいなの作ってそっちに置いて行って。そっちのページにも引き継ぐのはとりあえずボドゲと英字と私のお気に入りだけ」
→（写して新しく詰めるか、リンクだけか、を訊いて）「写して新しく詰める」。一覧の行き来は「両方に『次／前』の一行」。

- 015 の案と designs/index.html はそのまま据え置き。新しい案はここに足す。
- 015 から写したもの：bodoge.html（ボードゲームの卓）、kumikae.html（英字が組み替わる誌面）、window.html（時間で変わる作業部屋。本人のお気に入り）。
- window.html は main に出ていた版（注釈・設計図・カメラの層を足す前）を写した。層を足した版は 015 のブランチにだけある。

本人：「それさ、windowsのタブかsafariのタブみたいにできない？時系列順っぽくすれば別に前と次の区切りもできるんじゃん」
- designs/index.html を、ブラウザのタブのような一覧にした。古いものから左→右、区切りに日付（11/19〜11/25／11/26〜）。開いたときは一番新しいタブ。
- タブを押すと下に案が開く。上のアドレス欄の右に「別のタブで開く ↗」。開いているタブは URL の # に残る。
- 「次／前」の一行は外した。016-next/index.html は designs/index.html へ飛ぶだけ。
