| 目的 | AlterDesign（株式会社アルターデザインコンサルティング）のコーポレートサイト案 |

## いまの形

開いた瞬間に「この会社の仕事を、やってみてください」と**仕様を問う**。

```
5問（画面／承認/金額／不在時／修正時）
  ↓  決めたことがそのまま作られる（決めなかったものは作られない）
生成（左で思考が流れ、右に部品が組み上がる）
  ↓
漏れの採点（想定10件中）
  ↓
「指摘を反映して直す」→ その場で直り、実測秒数が出る
  ↓
従来との対比（結合テストまで見つからない vs いま直った）
```

- ファーストビュー 1 画面完結（実測 767px）。**プレゼンでスクロールはしない**という前提
- 左「仕様」／右「出てきたもの」の 2 カラム。左で考え右に出る構図がインパクト
- マウス不要（矢印キー・Enter・`/` でページ内移動）
- 自動スクロールは**一切しない**。生成後は畳んで縦を詰める
- 白基調。琥珀は `#b45309`（白地で読める濃さ）
- 会社説明（上流工程中心とは／サービス／理念／このページについて／会社概要）は hero の下

## 却下された方向（繰り返さない）

| 案 | 却下の理由 |
| --- | --- |
| ドラクエ風・レトロゲーム風 | 使い古されすぎ。懐古は「実験的・チャレンジ」と矛盾する |
| 黒基調（002 のターミナル配色） | 読みにくい。**白基調で確定**。コントラストのために黒へ戻すのも却下 |
| AI の口調にユーモアを混ぜる | 却下。丁寧・有能のままにする |
| 触ると反応が返る（極端な数値へのツッコミ） | 却下 |
| このページ自体を生成物として見せる（自己言及） | 却下 |
| AI が気を利かせすぎる（やりすぎて自制する） | 却下 |
| 生成を一度失敗させる | 却下 |
| 題材選択のデモモード | 廃止。**問題（腕試し）だけ**にする |
| 会社説明を後ろに隠す | 却下。概要は最初に出す |

## 未解決・次にやること候補

1. **「面白い（funny）」がまだ足りない可能性。** interesting は達成したが、笑い・驚きは弱い。
   遊びの担保が腕試しの挑戦性だけになっている
2. **速さ以外の強みの表現。** いまは所要秒数を押し出しているが、価値は「間違いに早く気づける」こと。
   別案: 同じ仕様から違う実装を出して比べる／運用中の仕様変更への追随を見せる
3. **満点が取りやすい。** 各問の正解が常識的に選べる位置にある。
   トレードオフのある問い（正解が一つに決まらないもの）を混ぜると悩ませられる
4. **ロゴが未着。** 実ロゴが来たら差し替える（現在は文字のみ）
5. 削除した冗談の題材（**会議のコスト**／**部長の機嫌**）は git 履歴にある。
   腕試しの題材として復活させる場合、題材ごとに問いと漏れの指摘を作る必要がある

## 運用メモ

- **CSS/JS は `?v=N` 付き。中身を変えたら番号を上げる。**
  GitHub Pages は Cache-Control を設定できないため、上げないと古い版が表示される（実際に一度ハマった）
- ローカル確認は静的サーバが必要（`file://` では動かない）
- 002（`designs/002-alter-design-terminal/`）は黒地のターミナル案。配色は却下されたが別案として残置
