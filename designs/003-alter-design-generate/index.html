上流工程中心とは

要件をすべて固めてから作り始めると、作っている間に前提が変わり、 できたものが要件と合わなくなります。だから順序を変えます。

  1. 1決める業務の単位、画面、テーブル、業務ルールを決める。
  2. 2すぐ動かす決めたことが、そのまま動く状態を作る。
  3. 3触って直す動くものを触って、決めたことの間違いに気づく。

このページの上で見たのは 1 と 2 です。3 は実際の案件で、使う人と一緒に回します。 AI とローコードは、1 から 2 までの距離を詰めるための道具として使っています。 道具が目的ではありません。

このページについて

会社案内を読ませる代わりに、事業内容をその場で実演する作りにしました。 理念に「遊ぶように働く」と書いてあるなら、サイトも遊んでいるべきだからです。

マウスは要りません。矢印キーと Enter だけで進み、/ でページ内を移動できます。 実装は AI（Claude）が行いました。素の HTML / CSS / JavaScript のみ、ビルド工程なし。 なお「生成」はデモとして用意した結果で、その場で推論しているわけではありません。 実演したいのは推論ではなく、上流で決めたことがそのまま動くものになるという順序の方です。
