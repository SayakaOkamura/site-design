## Alter から引く：CM の型で（2026-11-19）

本人：「**Alterって要は別解みたいな話じゃん。そこから固有の何かを引っ張ってこれないかな。遊びながらの方を形にしようとするとどうしてもゲームとか画面遊びに寄っちゃう**」
→（もう一方／変える／alter ego と出して、alter ego は 014 で使ったので外す、と言った）「**alteregoの方も面白いけどね。うん、だから別解だってば**」
→「**これを、GeminiのCMみたいに活かすにはどう使うかって話をしようとしてんの**」
→（下の二つを出して）「**おもしろい。どっちも覚えておいて**」

CM の型（参考資料の Chrome CM）：
```
1  誰でも知っている言い回し      「右に出る者はいない」
2  文字どおりに絵にする          人が右へずれる（「不具合ではありません」で、わざと変に見せる）
3  その絵が製品の中で本当になる  ボタンが本当に右上にある
```

**別解**
```
1  参考書の解説の「【別解】」
2  サイトが問題集の解答ページの形。問題 → ふつうの解答 → 横に【別解】の欄
3  【別解】の欄に会社のやり方（公式「AI × ローコードで、『上流工程中心のシステム開発』に革新を」）。名前の Alter もそこで回収
```
形が分かりやすく、情報も渡しやすい。

**alter ego（もう一人の自分）**
```
1  「もう一人の自分」
2  画面の要素が二重に映る。表示が崩れたように見せる（CM の「不具合ではありません」と同じ手）
3  ずれていたもう一人が、仕事を一緒に進める AI だと分かる。014 の軸「並走しながら」とも重なる
```
CM と同じく、変に見せてから回収する驚きが作れる。
