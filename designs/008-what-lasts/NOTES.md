## なぜ作ったか（2026-09-03、本人の言葉から）

> 「技術は変わる、本質はなんだ」って言葉から逆算して、
> 今迄の知見を使ってもう一個新しいやつざっくり作ってみたい

## 逆算

**変わるもの**：道具の名前（AI・ノーコード・Claude Code）、動き、見た目の流行。

**005・006-G・007 は、全部その「変わるもの」で組んである。**
3本とも仕掛けが主役で、**仕掛けの無い一本が無かった。**

だから引き算にした。**仕掛けを全部落として、残ったものを置く。**

1. **読めること**（15px ／ 行間 1.95 ／ 一行 38字前後 ／ 白地）
2. **公表されていることだけ**（公式サイトの言葉のまま）
3. **出どころと、いつ時点か**（下に一行）

### 引き算は間違いだった（同日、作り直した）

> 今迄の知識全部を複合した結果008ができたんだとしたら、取る要素間違えてると思うんだけどどう？

**合っている。取ったのは知見ではなく制約だった。**
上の3つは全部「守るべき下限」で、案の中身ではない。
**やってはいけないことの一覧を守ると出てくる形**を、設計だと言っていた。

本当に取るべきだったのはこちら。

| 知見 | どこで得たか |
| --- | --- |
| **実演で見せる。言葉で言わない** | 005「決裁欄が空で返ってくる」／G「空欄が3つ出る」／007「押していないのに動いて止まる」 |
| **形にすると、足りないところが出る** | 005・G の筋。**会社の仕事そのもの** |
| **止まって、人に渡す** | 007 |
| **一手に重みを持たせる** | 005 は操作3回、全部判断のある操作 |
| **名乗りは最後** | 005・G・007 に共通 |

**根の間違いは「本質」を引き算で探したこと。**積み上がっていた知見が言っているのは、
本質は**「先に形にして、足りないところを出す」という動作**だということ。
**動作は引き算では見せられない。**だからこの形は原理的に空になる。

## 実演は一つだけ（2026-09-03 に足した）

**下限（削る・混ぜない・読める・公表情報だけ・入口はふつう）はそのまま。**
真ん中に足りなかった一つを入れた。

上の案内に、**答えのある4つと、答えの無い2つを同じ並びで置いてある。**

    企業理念  サービス  会社概要  お問い合わせ  料金  実績・事例

- **見た目で区別しない。**薄くも小さくもしない
- 答えのある4つは、押すと節へ飛ぶ
- **無い2つは、押すと無いと返る**（`料金は、このページには置いていません。`）
- **言葉で先に言わない。**押した人にだけ起きる

**これが「先に形にして、足りないところが出る」の最小の形。**
押すという一手が、足りないところを出す。

**「会社に無い」とは言っていない。**言っているのは「このページには置いていない」。
出どころ（公式サイト）と確認日は下に出してあるので、そこは読める。
007 で「事例はありません」を落としたのと、**言い方の線は同じ**。

**JavaScript はここだけ。**10行ほど。前は一行も無かった。

## 色は公式サイトから取った（2026-09-03）

> 別にこの色味にこだわる必要はないと思うけど…
> 会社のイメージカラーが紫だからそこつかうのもありかもね

実物の computed style を読んで取った。**公式は白地に濃い紫。**

**一度目は失敗した。**本文 `#2a0e3e` と 12px の節見出し `#654087` だけで組んだ結果、
**ほぼ黒に見えた。**

> 本当に紫？これ、どこを？？

`#2a0e3e` は暗すぎて 15px の本文では黒と区別がつかない。`#654087` を使っていたのは
**12px の節見出しと、リンクの hover だけ**で、面積が無かった。

**公式サイトも、文字では紫を出していない。**あの紫は**ロゴと背景の線画**で出ている。
つまり「紫にする」は色を差し替える話ではなく、**面積を作る話**だった。

| | 値 | どこ |
| --- | --- | --- |
| 地 | `#ffffff` | 公式は白地 |
| 本文 | `#2a0e3e` | 公式でいちばん多い色（ほぼ黒に見える） |
| **理念** | **`#4b2470`** | **ここでいちばん面積を取る**（28px の明朝） |
| 節見出し・リンク | `#654087` | 公式のリンク色。12 → 13px に上げた |
| 帯と下の地 | `#f7f3fb` | **薄く敷いて面積を作る。**絵を置かない代わり |
| 罫 | `#e3d8f0` | 灰から紫寄りに |

005 から持ってきていた茶系（`#a8632f`）はやめた。
**「黒地は読みにくい」（002 の却下）はそのまま生きているが、
公式が濃い紫を使っているのは事実**なので、地に敷く案は潰れていない。

## 書いてはいけないもの

- **レビューで出てきた言葉**（本人の指示）。あれは解釈で、会社の言葉として
  出ていない。「個性を生かして夢中になれる」も、採用をグループでまとめる話も、
  **画面には載せない**
- **理念の意味。**一行そのまま置く。繋げるのは読者の仕事
- **こちらの言葉**（進め方・やらないこと・料金の理由）。007 で落としたのと同じ理由
- **仕掛けの説明。**この一本には仕掛けが無いので、無いことも書かない

## 未解決

1. **実演が一つで足りるか。**押した人にだけ起きるので、**押さない人には何も起きない。**
   案内に混ぜてあるぶん、気づかれない可能性もある
2. **「遊びつつ、変遷についていく」の「変遷」が入っていない。**
   > 遊びつつ、変遷についていく感じを出せると面白いな
   遊び（押せる）は入ったが、**変わっていく感じは無い。**
   年代で見せる案（A）と、描かれ方が変わる案（C）は、
   **他の人が似たものを作っているので取り下げ**（2026-09-03）
2. **公式サイトとの差が小さい。**白地・紫・同じ4節・同じ言葉なので、
   **「今のサイトと何が違うのか」を聞かれる。**いま違うのは寸法（読みやすさ）と、
   出どころの一行だけ
3. **理念を頭に置いたのは、こちらの判断。**公式はヒーローの一行が頭で、
   理念は節の一つ。**入れ替えている**
