## 実演は一つだけ（2026-09-03 に足した）

**下限（削る・混ぜない・読める・公表情報だけ・入口はふつう）はそのまま。**
真ん中に足りなかった一つを入れた。

上の案内に、**答えのある4つと、答えの無い2つを同じ並びで置いてある。**

    企業理念  サービス  会社概要  お問い合わせ  料金  実績・事例

- **見た目で区別しない。**薄くも小さくもしない
- 答えのある4つは、押すと節へ飛ぶ
- **無い2つは、押すと無いと返る**（`料金は、このページには置いていません。`）
- **言葉で先に言わない。**押した人にだけ起きる

**これが「先に形にして、足りないところが出る」の最小の形。**
押すという一手が、足りないところを出す。

**「会社に無い」とは言っていない。**言っているのは「このページには置いていない」。
出どころ（公式サイト）と確認日は下に出してあるので、そこは読める。
007 で「事例はありません」を落としたのと、**言い方の線は同じ**。

**JavaScript はここだけ。**10行ほど。前は一行も無かった。

## 隠しコマンド（2026-09-03 に足した）

**既定では何も出ていない。**`/` を押した人にだけ、下に道具が出る。

- 何も知らない人には、ふつうの会社案内のまま（**役割はHP**。広告っぽくしない）
- 気づいた人には、**案内が応答する。**007 の体験がここに入る
- **技術邁進感は速さで出す。**キーだけで全部辿れて、待たされない。言葉では足さない

    /理念      企業理念へ
    /サービス   サービスへ
    /会社概要   会社概要へ
    /問い合わせ お問い合わせへ
    /料金      このページには置いていません
    /実績      このページには置いていません
    /出どころ   いつ時点の情報か

- 打つと絞り込む。`enter` か押すと動く。上下キーでも選べる。`esc` で閉じる
- **中身はこのページにあるものだけ。**無いものは「置いていません」と返す。
  会社の言葉は増やしていない
- **押せることは、下に `/` の一文字だけ置いて合図する。**何も書かないと誰も
  気づかない（007 で学んだ）。書きすぎると仕込みでなくなる。押しても開く
- ソースを読んだ人にだけ、コンソールに一行。**書かない遊び心**

### 日本語入力（2026-09-03 に直した）

> 多分日本語入力対応になってない

**なっていなかった。**はじめは `span` に文字を足していく作りで、`keydown` の
`e.key` を1文字ずつ拾っていた。**IME は変換の途中を `keydown` に出さない**
（`Process` などになる）ので、**日本語が一文字も入らない。**

こちらの動作確認も当てにならなかった。合成イベントで `key:'料'` を投げていて、
**実際の IME の通り方とは違う道**を試していた。

直したところ。

- **本物の `<input>` にした。**見た目は素の一行のまま（枠も地も無し）。
  点滅はブラウザの caret に任せる（自作の四角をやめた）
- 打った文字は `input` と `compositionend` で受ける
- **変換の途中は絞り込まない。**読み（じっせき）で絞ると一覧が空になって、
  壊れて見える。確定してから絞る（`composing` の旗）
- **変換確定の `enter` で走らせない**（`e.isComposing` を見る）。
  でないと「実績」を確定した瞬間に走ってしまう
- 一覧を押すときに焦点を外さない（`mousedown` を止める）

## 理念を実演する（2026-09-03）

> 理念である遊ぶように働く、が一番強くて

**ここまで、理念を実演している案が一つも無かった。**005・006-G・007 は3本とも
「決める」の話で、005 の NOTES に目的として書いてある「理念の体現」は空いたまま。

**理念の一行だけ、触ると動く。**

- 文字を一つずつに割って、**触ると持ち上がる**（3px、色は `#654087`）
- **押すと跳ねる**（0.42秒。同じ字を続けて押しても跳ねる）
- **動くのは理念の一行の上だけ。**ほかは動かない
- 読めなくはならない。**必ず戻る**
- 動きを切る指定では動かない（CSS 側で切ってある）
- `<br>` は残したまま文字を包むので、二行の組みは崩れない

**会社案内が全部跳ねると広告になる。**が、ここは「遊ぶように働く」と
書いてある場所なので、**跳ねてよい一箇所**。

**まだ弱い。**触らないと起きないので、気づかない人には理念は一行のまま。
そこは実演としては弱い。**改良の余地**。

## 006 の線を、縦に引き直した（2026-09-03）

> せっかくあのくねくねモーション作ったしあれも使いたいけどなあ
> うねりっていうか006の話ね

006-G は**横一枚を辿る線**だった。ここは縦のページなので、**縦に落ちる一本**にした。

- 組み方は G のまま：**直線 → 円弧 → 直線。曲がるのは円弧の中だけ**
- 点を通す曲線（Catmull-Rom）は使わない。**ぶよぶよになる**（G の NOTES に理由）
- 曲がるのは**節の切り替わり**。読み進みと曲がりが揃う
- 振り幅は**円弧2つぶん**（半径 40 × 2 = 80）。S字がきれいに閉じる大きさ
- **読むほど引かれる。**進み具合を兼ねる（G の下の線と同じ役目）
- 長さは**実測**（`getTotalLength`）。**直値で書かない**（G で一度ずれた）
- **文字の下は通らない。**本文の左の余白に置く。1120px 未満では出さない
  （余白が無くなって本文に乗る）
- 動きを切る指定では、引く動きなしで全部出す

紫（`#654087`）で 2px、不透明度 0.5。**公式サイトの背景が紫の線画**なので、
線を敷くのはそこと揃う。

### 両端に理由を持たせた（同日）

> 悪くない、けど必然性がない。たとえばロゴが回転して下にこの線が伸びるとか…
> だとしてもあんまり、配置に理由がないな……

**そのとおりで、余白に置いてあるだけだった。**006 の線には理由があった
（**辿る道そのもの**だった）。ここでは装飾になっていた。

**線の両端に理由を置いた。**

- **始まり＝社名の左の輪。**開いて一度だけ回り（0.8秒）、
  **回り終わったところから線が伸びる**
- **終わり＝お問い合わせの宛先。**最後だけ本文へ入り込んで、宛先の手前で止まる
- **会社案内は、名前から始まって連絡先で終わる。**線の両端がその二つ

輪から余白へ移るところは、振り幅 200px を**半径 100 の円弧2つ**で受ける
（S字の半径は振り幅の半分にすると閉じる）。節の切り替わりは半径 40。
**曲がるのは円弧の中だけ**という G の組み方は通してある。

### 罫線を引き受けた（同日、外に案出しを投げてから）

> いや微妙、理由のある線を考えるのが苦手ならツール使って外注して

3方向（情報構造／会社の仕事／読む行為）に案出しを投げて9案。**採ったのは
「区切りに見えていたものが、一本だった」。**

**線を新しく置くのをやめた。**節を分けている**罫線を、線が引き受ける。**
社名の輪から下りて、1本目の罫線で東へ渡り、右余白を下りて、2本目で西へ渡る。
最後は宛先の手前で止まる。

| 何が | どこを決めるか |
| --- | --- |
| 罫線の y（実測） | **曲がる位置。**罫線がそこで終わっているから曲がる |
| 本文の箱の左右 | **振り幅。**38em の組みが決めている |
| 節の下の空き（`padding-bottom`）と次の節の上の空き、その小さいほう | **半径。**曲がるのは空きの中だけ |
| 社名の輪／宛先 | 両端（前から理由が付いている2点） |

**選んだ数字がゼロ。**「なぜそこに置いたか」に答える必要が無い——**罫線が
もともとそこにあったから。**余白に何かを敷いたのではなく、置いてあった家具が
繋がっていた、という形。

- CSS の罫は透明にして、**線が描く**（`.threaded` を JS が付けたときだけ）。
  **JS が動かなければ罫線はそのまま残る**
- 太さと色は罫に寄せた（1.5px / `#cbb8e0`）。**インクを増やさない**
- **引く動きはやめた**（同日）。

  > この線の動き普通に邪魔だなあ

  スクロールで引いていたが、**引き終わるまで罫線が欠けて見える。**
  罫線は家具なので、途中まで描かれている状態がそもそも邪魔だった。
  **最初から全部引いてある。**動くのは社名の輪の一回転だけ。
  （006 の「読むほど引かれる／進み具合を兼ねる」は、ここでは捨てた。
  あれは辿る道だったから成り立っていた。罫線を引き受けた線には合わない）

### 円弧の向きが逆だった（同日、外注で見つかった）

`sJog()` の sweep フラグが**両方逆**だった。SVG は y が下向きなので
`sweep=1` が画面の時計回り。正しい対応は、

    下→右 0 ／ 右→下 1 ／ 下→左 1 ／ 左→下 0

逆にすると、SVG は小さいほうの弧を選ぶので**別の中心の円弧**になり、
直線との継ぎ目に **90度の角が2つ**できる。「曲がるのは円弧の中だけ」という
006 の規則が、実装では破れていた。2px・不透明度0.5・余白の中だったので
気づいていなかった。

### 落ちた案（繰り返さない）

| 案 | 落ちた理由 |
| --- | --- |
| 節の項目数で本文からの距離を決める | 一段の幅を人が選んでいる。最後の円弧（r=111）が入らない |
| 問答の対ごとに震わせる | 振り幅が**いちばん詰まった行**で決まる＝組みの都合 |
| 答えを1つ通るごとに一段寄る（積算） | **規則は最も厳しいが、うねらない。**「006 のを使いたい」と正面から反する |
| 止まったところが膨らむ（滞在） | 全員に起きて因果も閉じるが、表しているのが「注意」で会社の中身ではない。線が後から書き換わる |
| 決めた節のところだけ折れる | 押さない人には何も起きない（理念の実演と同じ弱点の二重化） |
| 理念の押した字が道の x を決める | 押す場所と変わる場所が離れていて因果が見えない |
| 節ごとに往復する2車線 | 余白にうねる輪が並ぶ＝却下済みの「飾り」に見た目が近い |

**滞在の案は、この上に後から重ねられる**（座標の担当が違う）。ただし先に
こちらを単独で成立させてからでないと、また「途中の振りが形の都合」に戻る。
