## 注文（本人の言葉）

> 全体的に **16bit** くらいのイメージ。でもある程度見やすく整える。
> マウスは使うけど**スクロールはしない**イメージ。
> 太陽だか夕日だかを背景に**勇者が走ってて、走る位置は変わらない**。
> 左側に**常にメニューコマンド**が出てる。そこに企業概要とか理念とかデモとかの選択肢を入れる。
> 選択すると、**ポップアップみたいな感じで概要が出てくる**。デモについては後で詰める。
> 走ってる**地面の下**あたりに常に**お問い合わせとポリシー**のコマンドを置いておく。

### 原因は二つ、どちらもこちら側

**一つ目、出典を当たらずに「無い」と書いた。**ポリシーを「会社が出している文が無い」と読んだが、
**無いのではなく外に出していた。**`grep -o 'href="[^"]*"'` を一度通せば分かった
（トップから外へ出る先は三つしかない——PDF・mailto・BlueMeme のポリシー）。
**「見当たらない」と「無い」は別。**

**二つ目、枚数に合わせて文を削った。**「2 枚以内」は本人の指示だが、
**それは削って合わせろという意味ではなかった。**削った結果、住所も理念の半分も消えている。
**枚数と中身がぶつかったら、枚数のほうを譲る**——会社概要だけ 3 枚にした
（2 枚だと `2 / 2` と「とじる」が枠の外へ落ちる。1264×671 で実測 395px、上限 403px）。

**最後の一手を表にした。**お問い合わせだけ特別扱いしていたのを `GO` にまとめ、
**公式が出している先だけ**を指す（mailto／BlueMeme）。こちらで行き先を作らない。

## 勇者の絵（2026-09-15）

本人：「**絵をちゃんと描き起こすか、敵を先に決めるか**」→「**やってみて。敵は後**」。

**11×15 の二コマ → 24×22 の四コマ。**canvas に点で打つ。
地図は **index.html の中に文字の絵のまま**置いてある（`var HERO`）。点を一つ書き換えれば絵が変わる。

```
① 接地   前足が着く。後足は後ろで浮いている
② 沈み   体がいちばん低い。支え足の膝が曲がる
③ 通過   支え足は真下。もう一方は膝が上がる
④ 伸び   体がいちばん高い。両足とも地面から離れる
```

**輪郭だけで見分ける**（影法師なので、中の線は無い）。輪郭に足したのは三つ。

| | なぜ |
| **剣**（前・右へ） | **向きを言う**のはこれ。敵は右から来る。**振らない**——腕を振らせると胴から離れて点に見える（11×15 で踏んだ穴） |
| **外套**（後ろ・左へ） | **走っていること**を言う。脚より外套のほうが速さを出す |
| **脚**（前後） | 一歩は 8〜9 粒。**どのコマでも脚の長さは変えない**——変えると伸び縮みして見える |

### 描きながら踏んだ穴

| | 何が起きたか | 直し方 |
| **襟巻きが腕に見えた** | 最初は襟巻き（細い帯）を後ろへ流した。**細い棒は腕に見える**ので、剣を持つ腕と合わせて「腕が二本、前後に伸びた人」になった | **面にした。**外套なら腕と間違えない |
| **外套が甲羅になった** | 面にしたら今度は大きすぎて、胴ごと覆う丸い塊になった（虫の背中） | 幅を 7 粒 → **5 粒**に絞り、裾を細らせる |
| **雪だるま** | 頭と胴が同じ幅だった | 頭を一粒細くして、顎をさらに細くする |
| **脚が山に溶けた** | 勇者の色が `--hill`（近くの山と同じ）だった。重なると脚が消える | **勇者だけの色**（`--hero`）。いちばん手前なので**いちばん濃い** |
| **二重に跳ねた** | 上下の揺れを CSS の `bob` で足していた。四コマそれぞれで胴の高さが違うので、外から足すと沈みのコマでさらに沈む | **揺れは絵の中だけ。**`bob` は外した |

### 却下：逆光の縁

右端の一粒だけ明るくして、夕日の逆光に見せた（太陽は勇者の右で沈んでいる）。**やめた。**
**山には縁が無いのに勇者だけ光ると、同じ夕日の下に見えない。**
脚は二粒しかないので**半分が光って**脚が黄色く見え、刃も金色になって影法師でなくなる。
**入れたい版が要るなら、`draw()` で右隣が空の粒だけ色を変えれば戻せる。**

### 確かめた窓

1264×671／600×620／600×420（iframe で並べた）。
狭い窓では勇者が真ん中（`left:50%`）に戻り、**太陽の前に立つ**——濃い影が明るい丸に重なって、むしろ見やすい。
メニューとは 70px 以上あいている。

## 窓の置き方

```
左        メニュー（常時）
右上      ポップアップ（真ん中あたり）
地面の下  お問い合わせ・ポリシー（常時）
```

**ポップアップは右上**（本人：「下じゃなくて右に出せない？」「**右上真ん中らへん**」）。
下に出していたときは**画面の幅いっぱい**を占めて、勇者も地面も隠れていた。
右に寄せると**左の窓・勇者・地平が全部残る**——勇者が 34% なので、右半分が空いている。
狭い窓（640px 以下）だけ、下いっぱいに戻す。

そのあと**もう一段、中央と上へ**（本人：「**もうちょい真ん中寄せて、もうちょい上**」）。
右端からの余白 54px → **120px**、上から 24% → **17%**。
1264 の窓で測ると、**窓の左端が画面のちょうど真ん中**（625 / 632）に来て、
**上は名乗りのすぐ下**。勇者（34%＝430px）とは重ならない。
これ以上は上げられない——上げると名乗りにぶつかる。
