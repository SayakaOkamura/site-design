```

```

canvas に点で打つ。地図は **index.html の中に文字の絵のまま**置いてある（`var HERO`）。
`#` が体、`o` が目。**点を一つ書き換えれば絵が変わる。**

**一度目（4.5 頭身）は捨てた。**走りの割り方・剣・外套はそのまま持ち越して、
**頭を全体のちょうど半分**に。胴が短くなったぶん小さく見えるので、粒を 5px → **6px**（132px）。

```
① 接地   前足が着く。後足は後ろで浮いている
② 沈み   体がいちばん低い。支え足の膝が曲がる
③ 通過   支え足は真下。もう一方は膝が上がる
④ 伸び   体がいちばん高い。両足とも地面から離れる
```

輪郭に足したのは四つ。

| | なぜ |
| **頭**（全体の半分） | かわいさはここで決まる。丸くして、てっぺんに毛を一本。**胴より広く**——同じ幅だと達磨 |
| **目**（前寄りに二つ） | **影法師でも目だけは光らせる。**2頭身は輪郭だけだと**のっぺらぼうの影**で、かわいくならない。目を入れると顔の向きも出る |

**駅は足もとへ引っ越しただけ**で、文は一字も削っていない。

**こちらの読み違い。**枚数が減ったので短い窓のはみ出しも消えると書いたが、**消えない。**
落ちていたのは駅の枚ではなく**事業内容・設立・株主の枚**で、それは二枚目としてそのまま残っている。

問いは三つとも**短く、ふだんの言葉**にした（「〜ますか」から「〜？」へ）。

いまは——

| 問い | 出るところ |
| **方針** | やること（一本目）／要るもの |
| **どのくらい** | 進め方／最初の一週間 |
| **先々** | やること（二本目） |

**どの問いも、答えが必ずどこかに出る。**出ない問いがあると、選んだ意味が無い。

お題は三つ。組み合わせは 27 通りのまま。

```
聞けば答えてくれるものを、社内につくりたい
話しただけで、記録が残るようにしたい
寝ているあいだに、仕事が終わっていてほしい   ← ふざけたお題
```

**三つ目はわざと冗談**（本人：「3 でふざけるか」）。**願いはふざけて、答えは大真面目に返す。**
そこが可笑しいし、同時に「**どんな言い方で入れても形になる**」の証明にもなる。
理念（遊ぶように働く）にもそのまま乗る。

### ここで二度はずした

### 戻せるようにした
