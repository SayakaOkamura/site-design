# 011 RPG — 一から作り直し

## 次回ここから（2026-09-14 セーブ時点）

**今日やったこと。**009 までを全部たたんで、**ゲームとして一から作り直した。**
本人「一から別のもの作る。一旦頭リセットして。**これまでのルールも撤廃。失敗だけ一応頭に入れておいて**」
→「**今回は明確にゲームをやる**」。

**出来ているのは「画面」まで。**まだゲームではない。

```
できた   夕日の一画面（スクロールしない）／走る勇者（定位置・二コマ）
         左の常時メニュー／右上のポップアップ（▼ で送る、最大 2 枚）
         地面の下にお問い合わせ・ポリシー／十字キーとマウスの両方
まだ     デモ（＝ゲーム本体）。メニューの四つ目は「準備中です」の枠だけ
```

### 明日いちばんに決めること：**敵は何か**

これが決まると、**勇者が何をするか**も**デモが何をするゲームか**も決まる。
本人の言葉：「**デモで後々敵出したい**」——そのために勇者を 34% まで左へ寄せて、
**右に 700px あけてある。**

**決まっていないのは三つ。**
1. **敵は何か**（課題？決めごと？別のもの？）
2. **勇者は何をするか**（避ける／倒す／通す／選ぶ）
3. **勝ち負けを出すか**

- **地面の下（画面の 20%）**——お問い合わせとポリシーの二つだけ。まだ空いている

  確かめて一つ**穴が出た**（下の表の最後の行）

## 注文（本人の言葉）

> 全体的に **16bit** くらいのイメージ。でもある程度見やすく整える。
> マウスは使うけど**スクロールはしない**イメージ。
> 太陽だか夕日だかを背景に**勇者が走ってて、走る位置は変わらない**。
> 左側に**常にメニューコマンド**が出てる。そこに企業概要とか理念とかデモとかの選択肢を入れる。
> 選択すると、**ポップアップみたいな感じで概要が出てくる**。デモについては後で詰める。
> 走ってる**地面の下**あたりに常に**お問い合わせとポリシー**のコマンドを置いておく。

## 解禁したもの

- **003 の「レトロゲーム風・ドラクエ風は却下」**（使い古されすぎ／懐古は実験的と矛盾）。
  **本人がこの回で撤廃。**
- ただし**意匠は借りない**——枠・▼・コマンド一覧は **RPG 全般の作法**として借りるだけで、
  特定の製品の見た目には寄せない。

## いまの一枚（粗い）

```
ALTER DESIGN CONSULTING            空（帯で切る）
株式会社アルターデザインコンサルティング
AI × ローコードで、…                    ☀ 夕日（縞は丸の中だけ）

┌──────────┐
│▶ 企業理念 │                    遠い山（ゆっくり流れる）
│  サービス │                    近い山（速く流れる）
│  会社概要 │              🯅 勇者（定位置・二コマ）
│  デモを触る│  ────────────────────────  地面（縞が流れる）
└──────────┘
              ▸ お問い合わせ　▸ ポリシー
```

- **スクロールしない。**`html,body{height:100%;overflow:hidden}`。一画面で完結
- **一枚、多くて二枚**（本人「企業理念とか**一括か 2 枚以内**にしてほしい」）。▼ で送る（枠内スクロールは使わない）
  - **「文は削らない」はやめた。**枚数の指示が先。削ったのは**サービスの説明の二文目以降**だけで、
    **公式の題と一文目はそのまま。**理念と会社概要は**一字も削っていない**（詰め方を変えただけ）
- **題は漢字**（本人「**ひらがなで書かなくていい。そこは普通に読みやすくしておいて**」）。
  RPG の作法でひらがなにしていたが、**読みやすさを取る**
- **中身は公式サイトの言葉のまま。**足していない
- **ポリシーは「まだ用意がありません」**——会社が出している文が無いので、こちらで書かない
- **デモは枠だけ**（「じゅんびちゅう」）。後で詰める

## 作りながら踏んだ穴（同じ日）

| | 何が起きたか | 直し方 |
| 勇者が出ない | 二コマの点滅に**半拍の遅れ**を足していて、**両方消えている時間**ができていた | `step2` がすでに裏返しなので、遅れを外す |
| 勇者が市松模様 | 影を **7px 間隔**で置いているのに、一粒が `--px`（**4px**）だった | 一粒の大きさを影の間隔に合わせる |
| 勇者が点の集まり | **腕が胴から離れていた**（1px の孤立点） | つながった塊に描き直す。11×15 の二コマ |
| 山が歯車の刃 | `conic-gradient` の三角は**片側が垂直に切れる**。同じ形の繰り返しで階段に見えた | **SVG の稜線**にして、高さを散らす |
| 太陽の縞が四角い | `::after` が要素いっぱいだった | `mask` で**丸の中だけ**に |
| 太陽が見えない | 山より後ろに置いていた | `z-index` で山より手前へ |
| **空が色の迷子**（五度直した） | ①紫と赤紫で**虹色**（「こんな虹色じゃなくていいよ www」）②紺から始めて**暗すぎた**（「別に他の色にしなくていい」）③橙だけにしたら上が茶色くなって**砂漠**（「いま**砂漠みたいになってる**ぞ」）④ピンク寄りにしたら**ピンクでもない**（「**オレンジ系だけで収まらない？**」）⑤明るさで段を作ったら**夕日として明るすぎた**（「**明るさで作らないで、夕日としては明るすぎる**これ」） | **軸は明るさではなく彩度だった。**茶になるのは**彩度が落ちたとき**で、暗くしたときではない——`#7a3620`（砂漠）は彩度 60%、`#c23c0c`（いま）は**彩度 90%**。同じくらい暗いのに茶に見えない。**空は濃い橙で通し、明るいのは太陽だけ** |
| 空を明るくしたら太陽が溶けた | 芯も外も淡く、**背景と同じ明るさ**になった | 芯は白へ、**外の輪を濃い橙**にして縁を立てる |
| 明るい空で白字がぼやけた | にじむ影を敷いていた | **四方 2px の硬い縁**（16bit の作法） |
| 太陽のまわりに四角い暈 | `radial-gradient` の既定は `farthest-corner` なので、**92% で透明にしても角まで届かない** | `circle closest-side` を付ける |
| **▶ が二つ出る** | マウスを**乗せたまま**十字キーを使うと、`:hover` の印と選択の印が**同時に**出る。手は一つしか動いていないのに、印が二つ | `body.kb` を付けて、**キーに触れたあいだは `:hover` を黙らせる**（マウスが動いたら戻る） |
| 勇者だけ紺のまま | 影の色を `#140c2a` で**べた書き**していた（空を変えても付いてこない） | 山と同じ色を**変数から引く** |

**本人：「でもやりたいことはそんな感じ！合ってる」**——**方向は確定。**

## 窓の置き方

```
左        メニュー（常時）
右上      ポップアップ（真ん中あたり）
地面の下  お問い合わせ・ポリシー（常時）
```

**ポップアップは右上**（本人：「下じゃなくて右に出せない？」「**右上真ん中らへん**」）。
下に出していたときは**画面の幅いっぱい**を占めて、勇者も地面も隠れていた。
右に寄せると**左の窓・勇者・地平が全部残る**——勇者が 34% なので、右半分が空いている。
狭い窓（640px 以下）だけ、下いっぱいに戻す。

そのあと**もう一段、中央と上へ**（本人：「**もうちょい真ん中寄せて、もうちょい上**」）。
右端からの余白 54px → **120px**、上から 24% → **17%**。
1264 の窓で測ると、**窓の左端が画面のちょうど真ん中**（625 / 632）に来て、
**上は名乗りのすぐ下**。勇者（34%＝430px）とは重ならない。
これ以上は上げられない——上げると名乗りにぶつかる。

## 置いてある空き（意図してある）

  （本人：「勇者もうちょっと左にできる？**デモで後々敵出したい**」）。左の窓とは 106px あけてある
- **地面から下（画面の 20%）**は、お問い合わせとポリシーの二つだけ。まだ空いている
