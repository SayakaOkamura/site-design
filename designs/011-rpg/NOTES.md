```
① 接地   前足が着く。後足は後ろで浮いている

③ 通過   支え足は真下。もう一方は膝が上がる
```

### 会社概要から駅を抜いた（同じ日）

本人：「**あともうそこにアクセスいらない、会社概要の中**」。
会社概要は **3 枚 → 2 枚**に戻った。

```
会社概要 1 / 2   会社名・代表者・所在地
         2 / 2   事業内容・設立年月日・資本金・株主
```

**駅は足もとへ引っ越しただけ**で、文は一字も削っていない。
住所は**両方に残す**——会社概要の一枚目にも、アクセスの一枚目にも要る（\`ADDR\` を両方から引く）。
駅（\`ROUTE\`）を持っているのは、これで**足もとだけ**。

**こちらの読み違い。**枚数が減ったので短い窓のはみ出しも消えると書いたが、**消えない。**
落ちていたのは駅の枚ではなく**事業内容・設立・株主の枚**で、それは二枚目としてそのまま残っている。

**入り口を「困りごと」から「やりたいこと」へ。**

```
前  社内の申請が、紙とメールで回っている   ← 困っている話
    どこがいちばん詰まりますか（痛み）
    何ができていれば、うまくいったと言えますか（ゴール）
    最初はどこから手を付けますか（範囲）

いま 聞けば答えてくれるものを、社内につくりたい   ← アイデア
    どんな方針でいく？
    どのくらい、かける？
    先々、どうなっていてほしい？
```

問いは三つとも**短く、ふだんの言葉**にした（「〜ますか」から「〜？」へ）。
入り口の問いも「どんなことで困っていますか」→「**どんなことを、したい？**」。

**組み立て方も変えた。**前は 1 問目だけが「要るもの」で、3 問目が三か所に効いていた。
いまは——

### 踏んだところ：git から戻したら CRLF になっていて、置換が全部空振りした

`git apply -R` で戻した直後のファイルは **CRLF**（`core.autocrlf`）。
こちらの編集は LF で書いていたので、**検索文字列が一つも当たらない**。
エラーは「hit 0」で出るが、原因はテキストではなく改行のほうだった。
→ 読み込んだ直後に LF へそろえてから触る。
