どこまでが腕でどこからが剣か分からない。**前下がり 45° に振り下ろす**形にすると、
刃が体から離れるので読める。切っ先が地面のほうに落ちるのも、当たった先を指していい。

#### 待ちの id は二つとも持つ

「枠が開くまでの待ち」と「一行ずつの送り」で時計が二つある。
**開く前にキーで飛ばすと、あとから送りが動き出した**（飛ばしたはずの行が出てくる）。
`setTimeout` の id も持っておいて、両方止める。

#### 勝ちポーズの穴

刃を x15-16 に立てたら、**頭（x4-14）と一粒もあかずにつながって**、
「角の生えた塊」になった。**x16-17 へ**寄せて、あいだを一粒あけた。

#### 動きに透明度を持たせない

「たおした！」を `from{opacity:0}` で出していたら、**動きが走らない場で透明のまま**だった
（裏の窓で確かめていて気づいた）。`animation-fill-mode:both` を外しても直らない——
**動いている最中は from の値を取る**から。**大きさだけ動かして、透明度は素で 1** にした。
動きを止める設定（`prefers-reduced-motion`）でも、これなら文字は出る。

#### にげる／左半分の合図（同じ日）

打ち込んでいるあいだは消える（選んだ一行だけ残す画面なので、逃げ道も一緒に引っ込む）。

**何が起きるかを添えた**（本人：「にげる、でどうなるのかの注釈は入れておいて」
→「カッコがきにして」→「**デモを終了する、とかでいい**」）——
**にげる（デモを終了する）。**言葉は**リザルトの四角と同じ**にそろえた——
同じことをする手が二つあるので、**呼び方は一つ**にする。
RPG の「にげる」は**戦いから逃げる**ことだが、ここでは**デモそのものが終わる。**

いま   選んだ三つ →（20px）→ タスク

## ポップがメニューに乗っていたのを直した（2026-09-18）

**984×631・1000×600・1000×511 で、ポップの左端がメニューに 8px 乗っていた。**
四枚のときも二枚のときも乗っていたので、枚数の話ではなかった。

場所は `@media (max-height:640px) and (min-width:641px)` の一行。
**低い窓では縦に余地が無いので、横を使って折り返しを減らす**という直し（9/15）で、
`width:min(74vw,760px,calc(100vw - 380px))` としていた。

```
コメントの内訳   メニューの幅（最大 210）＋左の余白（最大 54）＋あいだ
実物            #menu{min-width:min(46vw,260px)}   ← 260。50px 足りない
```

**それだけではなかった。**`right` も `left` も `clamp` で**窓の幅について動く**ので、
**px 一つでは全部の幅に合わない。**

```
641px 幅   380 でちょうど（右 57.7 ＋ 左 25.6 ＋ 260 ＋ 影と間 32 = 375）
984px 幅   420 要る（右 88.6 ＋ 左 39.4 ＋ 260 ＋ 32 = 420）
```

→ **同じ `clamp` をそのまま引く。数字を当てずに、実物から引く。**

```css
#pop{width:min(74vw, 760px,
  calc(100vw - clamp(28px,9vw,120px) - clamp(16px,4vw,54px) - min(46vw,260px)
       - var(--px)*6))}
```

引くもの：右の余白 ＋ メニューの左の余白 ＋ メニューの幅 ＋ 両方の影（8+8）＋ あいだ（8）。

**8 窓で測って、すきまは全部ちょうど 8px。**どの窓のどの頁も天井を超えない。
低い窓では前より少し広くなる（641px で 12px、700×500 で 5px）ので、
折り返しを減らす狙いのほうも弱まっていない。

**px の取り置きは、実物から引く。**内訳をコメントに書いても、実物が変われば嘘になる。
