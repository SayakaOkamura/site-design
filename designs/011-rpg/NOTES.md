失敗だけ一応頭に入れておいて**」→「**今回は明確にゲームをやる**」。

**009 までの決めごとは、この案では一つも引き継いでいない。**失敗の記録だけ持ち込んだ。

## 注文（本人の言葉）

> 全体的に **16bit** くらいのイメージ。でもある程度見やすく整える。
> マウスは使うけど**スクロールはしない**イメージ。
> 太陽だか夕日だかを背景に**勇者が走ってて、走る位置は変わらない**。
> 左側に**常にメニューコマンド**が出てる。そこに企業概要とか理念とかデモとかの選択肢を入れる。
> 選択すると、**ポップアップみたいな感じで概要が出てくる**。デモについては後で詰める。
> 走ってる**地面の下**あたりに常に**お問い合わせとポリシー**のコマンドを置いておく。

  **本人がこの回で撤廃。**

## いまの一枚（粗い）

```
ALTER DESIGN CONSULTING            空（帯で切る）
株式会社アルターデザインコンサルティング
AI × ローコードで、…                    ☀ 夕日（縞は丸の中だけ）

┌──────────┐
│▶ 企業理念 │                    遠い山（ゆっくり流れる）
│  サービス │                    近い山（速く流れる）
│  会社概要 │              🯅 勇者（定位置・二コマ）
│  デモを触る│  ────────────────────────  地面（縞が流れる）
└──────────┘
              ▸ お問い合わせ　▸ ポリシー
```

- **スクロールしない。**`html,body{height:100%;overflow:hidden}`。一画面で完結
- **文は削らない。▼ で送る**（枠内スクロールは使わない）。理念 4 ページ／サービス 4 ページ／会社概要 4 ページ
- **中身は公式サイトの言葉のまま。**足していない
- **ポリシーは「まだ用意がありません」**——会社が出している文が無いので、こちらで書かない
- **デモは枠だけ**（「じゅんびちゅう」）。後で詰める

## 作りながら踏んだ穴（同じ日）

| | 何が起きたか | 直し方 |
| 勇者が出ない | 二コマの点滅に**半拍の遅れ**を足していて、**両方消えている時間**ができていた | `step2` がすでに裏返しなので、遅れを外す |
| 勇者が市松模様 | 影を **7px 間隔**で置いているのに、一粒が `--px`（**4px**）だった | 一粒の大きさを影の間隔に合わせる |
| 勇者が点の集まり | **腕が胴から離れていた**（1px の孤立点） | つながった塊に描き直す。11×15 の二コマ |
| 山が歯車の刃 | `conic-gradient` の三角は**片側が垂直に切れる**。同じ形の繰り返しで階段に見えた | **SVG の稜線**にして、高さを散らす |
| 太陽の縞が四角い | `::after` が要素いっぱいだった | `mask` で**丸の中だけ**に |
| 太陽が見えない | 山より後ろに置いていた | `z-index` で山より手前へ |
| **空が色の迷子**（三度直した） | 一度目：紫と赤紫で**虹色**（本人「こんな虹色じゃなくていいよ www 普通に夕焼け色で」）。二度目：紺から始めて**暗すぎた**（「これは暗いな、**別に他の色にしなくていい**」）。三度目：橙だけにしたら**上が茶色くなって砂漠**（「というかいま**砂漠みたいになってる**ぞ」「上の方が茶色だと**印象が暗くなる**」） | **茶は地面の色。**空に置くと空に見えない。**上は明るい赤みのピンクから、地平へ淡い金へ。**全段を明るく保ち、**暗さは影法師（山・地面・勇者）だけで作る** |
| 空を明るくしたら太陽が溶けた | 芯も外も淡く、**背景と同じ明るさ**になった | 芯は白へ、**外の輪を濃い橙**にして縁を立てる |
| 明るい空で白字がぼやけた | にじむ影を敷いていた | **四方 2px の硬い縁**（16bit の作法） |
| 太陽のまわりに四角い暈 | `radial-gradient` の既定は `farthest-corner` なので、**92% で透明にしても角まで届かない** | `circle closest-side` を付ける |
| 勇者だけ紺のまま | 影の色を `#140c2a` で**べた書き**していた（空を変えても付いてこない） | 山と同じ色を**変数から引く** |

**本人：「でもやりたいことはそんな感じ！合ってる」**——**方向は確定。**
