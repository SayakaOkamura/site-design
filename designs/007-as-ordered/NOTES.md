## いまの組み立て（2026-09-02 に方向を替えた）

**替えた理由。**005 も G も「一行の注文 → 形にする → 足りないところが出る」で、
題材だけ替えても**方向性まで似てしまう**（本人の指摘）。
先に作った2案（ふつうのサイトに作業画面を隠す／見積もりの注文を流す）は、
どちらもこの型だった。**型ごと替える。**

**サイトの案内そのものが Claude Code のセッション。**
訪問者がふつうに聞きたいことを、ファイルを読む形で返す。

**勝手に進む。でも選べる。戻れる。**（2026-09-02、三度直した）

| 形 | やめた理由 |
| --- | --- |
| 一手ずつエンター | **押す回数が多すぎた**（26回） |
| 人の行だけエンター（4回） | 選べない・戻れない。コーポレートサイトとして使えない |
| 下に「聞けること」の一覧 | **読むところが狭くなった** |
| **左に目次＋自動で進む**（いま） | — |

- 上から順に**勝手に流れる**（1つ終わると `PACE.turn` 待って次へ）
- **左の目次**は、置いてあるファイルの木（`サービス/` `進め方.md` …）。
  **無いもの（事例・料金）は並ばない**
- 押せばそこへ飛ぶ。**いつでも、何度でも。**読み終わったものに ✓、いま読んでいるところに縦線
- log は消さないので、上に遡れば前のものが残っている
- `space` で止める／また動かす、`esc` で流れている途中を最後まで出す、数字キーでも選べる
- 狭い画面（760px 未満）では、目次を上に横並びにする

**並びは会社サイトの順。**サービス → 進め方 → やらないこと → 実績・事例 → 料金 →
会社概要 → 登記・株主 → 理念 → お問い合わせ。

**変なところは「無いものが 0件として出る」こと。**
事例が無いことも、料金を置いていないことも、隠していないと言葉で言うのではなく
**検索の結果として見せる。**作りで分かる。

**「やらないこと.md」の中身は仮**（言われたとおりに作って終わること／
事例で説明すること／根拠のない数字を出すこと）。3つめは 003 から続く
こちらの規則を会社の姿勢として置いたもので、**本人に確認していない。**

## 借りた語彙（2026-09-02 に増やした）

「もう少し Claude Code 感」で足したのが後半6つ。

| 語彙 | どこ |
| --- | --- |
| `⏺` ツールの呼び出し／`⎿` その結果 | 全体 |
| `☐ ☒` やることの一覧 | 3手目・5手目・6手目 |
| 行番号つきの diff | 4手目 |
| 下の入力枠に打つ動き | 人の行だけ |
| `⏵⏵ auto-accept edits on` | 上の帯 |
| **`✻` 回る記号＋経過秒＋`esc to interrupt`** | 考えている表示。**いちばん効いた** |
| **`⎿ Updated ... with 4 additions and 1 removal`** | diff の上のまとめ行。単複も合わせる |
| **`⏺ Update Todos`** | 一覧の見出し |
| **`⏺ Bash(npm run dev)` と起動ログ** | 5手目。「動いている」を実物で見せる |
| **`(ctrl+r to expand)`** | Read の結果 |
| **`? for shortcuts` / `Context left until auto-compact: 78%`** | 下2行。割合は進み具合で減らす |

**借りるのは語彙だけ。画面の写しにはしない。**
文字の大きさ・行間・対比は読める側に寄せてある（14px / 1.85 / 13:1 / 90ch）。

まだ入れていないもの：**`/` を打つとコマンド候補が出る。**
主役が「注文」から「操作」へ寄るので、見てから決める。

**打つ動きは人の行だけ**（`>` の行を下の枠に打ってから上へ送る）。
Claude の地の文は1文字ずつ出すが、速さは一定にして待たせる間は作らない。

## 残した前提

- 注文は一行。言われたとおりに作って、動かして見せる
- **形にする → 足りないところが浮かぶ**（005 と同じ順。逆にしない）
- 未決の3つは**埋めない**（埋めると「AI が決めた」に戻る）
- 事例が無いことを隠さない
- **題材は G・005 と替えてある**（2026-09-02）。
  「デモで同じことばっかり見せるのはあれなので」。3本続けて見せると
  同じ話を3回聞くことになる。**比べるために揃える**より、**続けて見せられる**を採った
- **エンターを押すのは、人の行だけ。**Claude 側は自動で続けて出る。
  一手ずつエンターにしていたら 26回になって、多すぎた（2026-09-02 に直した）。
  turn が終わると次の注文が下の枠に打たれて止まり、そこでエンターで送る。**押すのは4回。**
  **人の行を自動で送らない**こと。送ると、読んでいる途中で話が進む。
  esc で最後まで、触る操作でも送れる（スマホはキーが無い）
- 動きを切る指定（`prefers-reduced-motion`）では流さず全部出す（指針4）
