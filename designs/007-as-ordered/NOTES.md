## いまの組み立て（2026-09-02 に方向を替えた）

**替えた理由。**005 も G も「一行の注文 → 形にする → 足りないところが出る」で、
題材だけ替えても**方向性まで似てしまう**（本人の指摘）。
先に作った2案（ふつうのサイトに作業画面を隠す／見積もりの注文を流す）は、
どちらもこの型だった。**型ごと替える。**

**サイトの案内そのものが Claude Code のセッション。**
訪問者がふつうに聞きたいことを、ファイルを読む形で返す。

**勝手に進むのは Claude 側だけ。選べる。戻れる。**（2026-09-03）

| 形 | やめた理由 |
| --- | --- |
| 一手ずつエンター | **押す回数が多すぎた**（26回） |
| 人の行だけエンター（4回） | 選べない・戻れない。コーポレートサイトとして使えない |
| 下に「聞けること」の一覧 | **読むところが狭くなった** |
| 左に目次＋**注文まで自動で送る** | **人の行を機械が送っていた**（下記） |
| **左に目次＋注文は人が送る**（いま） | — |

- **自動で流れるのは Claude 側だけ。**注文は枠に打たれて**止まる。**
  送るのは人（`enter`、または枠を押す）
- 1つ終わると `PACE.turn` 待って、**次の注文が枠に打たれる**（送りはしない）
- **左の目次**は、置いてあるファイルの木（`サービス/` `進め方.md` …）。
  **無いもの（事例・料金）は並ばない**
- 押せばそこへ飛ぶ。**いつでも、何度でも。**読み終わったものに ✓、いま読んでいるところに縦線
- log は消さないので、上に遡れば前のものが残っている
- `esc` で流れている途中を最後まで出す、数字キーでも選べる。
  **`space`（止める／動かす）は無くした。**勝手に進まないので要らない
- 狭い画面（760px 未満）では、目次を上に横並びにする

**開いた時点で出ているのは、上の2行だけ**（2026-09-03）

> 一番最初に表示したいようなものを最初から出しておいて、何もクリックしなくても
> 情報自体はあるようにしたいかも。表示したいものでも、このサイトのルールでもいいけど

> スクロールいらないくらいがいいな。その会社概要と理念だけでいいんじゃない、最初は

> さっきみたいに上に2行でまとめてるやつだけでいい

**起動枠の2行が、会社概要と理念をまとめたもの。**社名／理念／設立が、
押さなくても出ている。セッションには何も置かない。

- **打たない。送らない。**注文（`>` の行）は付けない。
  人が送っていない行を注文として出したら、自動で送っているのと同じになる
- 目次に ✓ は付かない。**セッションはまだ1行も動いていない**
- **次に打つ注文は、まだ出していない話題**にしてある（`next()`）。
  いまは全部が未読なので上から順だが、目次で飛ばされた話題は後から拾われる

**一度こうしてやめた形**（どれも 2026-09-03）

| 出したもの | やめた理由 |
| --- | --- |
| `CLAUDE.md` に**このサイトのルール**3行 | 会社概要と理念だけでいい、と決まった |

| **会社概要の札と理念の枠**（台本をそのまま） | 同じことが上の2行にある。社名が二度出ていた |

ルールの3行は（聞かれたことは置いてあるファイルで返す／無いものは無いと返す／
決まっていないことは埋めない）。**要るときのために残しておく。**

**1つめは、人の行なしで動く**（2026-09-03）

> 何ができる？スタートだと開いたときに困惑するかも、いきなり何？ってなる

> これだと次に繋ぐ動線として弱いな。クリックさせる動機がない

枠に注文を置いておく形は、三度やって三度外れた。**注文を置くのをやめた。**

| 1つめ | やめた理由 |
| --- | --- |
| `何ができる？` | 誰が誰に聞いているのか分からない。いきなりすぎる |
| `ここ、何？` | 問いかけには変わりなく、**押せることは言っていない** |
| `クリックしてください` | **押す動機がない。**次に繋ぐ動線として弱い |
| **人の行なし**（いま） | — |

**開いた瞬間、Claude 側だけが勝手に動く。**回る記号（`✻ 読んでいます…`）が出て、
`CLAUDE.md` を読んで、止まる。**動くものがあると目が行く。止まったところで
人に渡る。**人の行は出さないので、機械が注文を送ったことにはならない。
起動直後の Claude Code そのもの。

**ここだけ速さを別にする**（`RUSH`）

> ページのロードあるのにここでも初手ロードで待たされるとストレスあるかも。
> なしで。やるなら1秒以内

ふつうの速さ（think 1.5s ＋ tool 620 ＋ 1行 300…）だと、出そろうまで **2.5秒**。
**ページのロードのあとに、もう一度ロードを見せることになる。**

| | 開いた瞬間（`RUSH`） | ふつう（`PACE`） |
| --- | --- | --- |
| 回る記号 | 400 | 1500 |
| ツール→結果 | 150 | 620 |
| 塊の1行 | 60 | 200〜300 |
| 塊のあと | 60 | 410 |
| 次の注文まで | 400 | 1100 |

**出そろうまで 850ms。**次の注文が打ちはじめるのが 1250ms。
**読ませる間は、送ったあとの turn で取ればいい。**速いのは開いた瞬間の1回だけで、
`done()` を抜けるときに戻す。

止まったあと、枠に打たれるのは `何ができる？`。**一度は却下された行だが、
そのときは1つめだった。**いまはルールの4行を読んだあとなので、誰が聞くのかは

`T[0].q`（`ここのルールは？`）は、目次から押し直したときにだけ使う。
そのときは人が押しているので、`>` の行が出る。

返すのは `CLAUDE.md` の4行。**ここのルールと、押せること。**
    - ここは会社案内。聞かれたことは、置いてあるファイルで返す
    - 無いものは、無いと返す
    - 決まっていないことは、埋めない
    - 読みたいところは、左の一覧を押す。enter でも次へ進む

**最後の1行は、これまで削ってきた種類の文。**それでも置いたのは、
下の一言（`enter 送る`／`数字 選ぶ`）が小さくて薄く、**押せることが
そこだけでは伝わらない**ため。指針6ではなく、言われて置いている。
文言は画面が広いときの言い方（スマホでは一覧が上に出る。未確認）。

話題が10になったので、数字キーは10番目だけ `0`（実物と同じ数え方）。
下の一言は「1–9 選ぶ」から「数字 選ぶ」に替えた。

**並びは会社サイトの順。**（このサイト →）サービス → 進め方 → やらないこと →
実績・事例 → 料金 → 会社概要 → 登記・株主 → 理念 → お問い合わせ。

**変なところは「無いものが 0件として出る」こと。**
事例が無いことも、料金を置いていないことも、隠していないと言葉で言うのではなく

## 借りた語彙（2026-09-02 に増やした）

「もう少し Claude Code 感」で足したのが後半6つ。

| 語彙 | どこ |
| --- | --- |
| `⏺` ツールの呼び出し／`⎿` その結果 | 全体 |
| `☐ ☒` やることの一覧 | 3手目・5手目・6手目 |
| 行番号つきの diff | 4手目 |
| 下の入力枠に打つ動き | 人の行だけ |
| `⏵⏵ auto-accept edits on` | 上の帯 |
| **`✻` 回る記号＋経過秒＋`esc to interrupt`** | 考えている表示。**いちばん効いた** |
| **`⎿ Updated ... with 4 additions and 1 removal`** | diff の上のまとめ行。単複も合わせる |
| **`⏺ Update Todos`** | 一覧の見出し |
| **`⏺ Bash(npm run dev)` と起動ログ** | 5手目。「動いている」を実物で見せる |
| **`(ctrl+r to expand)`** | Read の結果 |
| **`? for shortcuts` / `Context left until auto-compact: 78%`** | 下2行。割合は進み具合で減らす |

**借りるのは語彙だけ。画面の写しにはしない。**
文字の大きさ・行間・対比は読める側に寄せてある（14px / 1.85 / 13:1 / 90ch）。

まだ入れていないもの：**`/` を打つとコマンド候補が出る。**
主役が「注文」から「操作」へ寄るので、見てから決める。

**打つ動きは人の行だけ**（`>` の行を下の枠に打ってから上へ送る）。
Claude の地の文は1文字ずつ出すが、速さは一定にして待たせる間は作らない。

## 残した前提

- 注文は一行。言われたとおりに作って、動かして見せる
- **形にする → 足りないところが浮かぶ**（005 と同じ順。逆にしない）
- 未決の3つは**埋めない**（埋めると「AI が決めた」に戻る）
- 事例が無いことを隠さない
- **題材は G・005 と替えてある**（2026-09-02）。
  「デモで同じことばっかり見せるのはあれなので」。3本続けて見せると
  同じ話を3回聞くことになる。**比べるために揃える**より、**続けて見せられる**を採った
- **エンターを押すのは、人の行だけ。**Claude 側は自動で続けて出る。
  一手ずつエンターにしていたら 26回になって、多すぎた（2026-09-02 に直した）。
  turn が終わると次の注文が下の枠に打たれて止まり、そこでエンターで送る。**押すのは10回**（話題の数）。
  **人の行を自動で送らない**こと。送ると、読んでいる途中で話が進む。
  esc で最後まで、触る操作でも送れる（スマホはキーが無い）。
  **2026-09-02 に目次を入れたとき、ここを壊した。**注文まで自動で送っていて、
  「自動入力にするのは AI 側だけ」と指摘されて 2026-09-03 に戻した。
  人の行を機械が送ると、**注文どおりに作る話が、機械が勝手に進める話になる**
- 動きを切る指定（`prefers-reduced-motion`）では流さず全部出す（指針4）
