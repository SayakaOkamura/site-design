## なぜ作ったか（2026-09-02、本人の言葉から）

> ・初見でいきなり飛ばさない、案を見せるために段階を踏む、
> 　注文ママのもの作らないとまずは入ってもらえないケースもある

この2つを前提に、「**Claude Code 感から入ってもらう / あー、注文どおりだな〜というやつ**」
として一本。**基本的に 005・G・これの3本で考える**（次にどちらへ持っていくかは未決）。

## 組み立て

**第一印象は、ふつうのコーポレートサイト。**理念 → サービス4本 → 会社概要 → 問い合わせ。
ここで変わったことをしない。**「注文どおりだな」と思ってもらうのが最初の画面の仕事。**

サービス 01 の下に「実物を見る」を置く。押した人にだけ作業画面が出て、**7手**で進む。

| 手 | 中身 |
| --- | --- |
| 1 | 依頼。「月末に、経理が止まる。」**一行しかない** |
| 2 | `/read` 現に動いているものを見に行く（聞いて回らない） |
| 3 | `/plan` **言われたとおりに形にすると宣言する。**足す機能は無い |
| 4 | `/apply` diff で出す。Excel の二重集計が消える |
| 5 | `✓` 動いている。**入っているのは、言われたことだけ** |
| 6 | `/check` ここから先がうちの仕事 |
| 7 | 未決の3つを罫で出す。**埋めない** |

**5手目で終われば「注文どおり」で完成している。**6〜7手が、注文に無かったもの。
そこが 005・G と同じ主張（形にする → 足りないところが浮かぶ）。

## 守った却下（IDEAS.md / 003・005・006）

- **黒地にしない。**002 のターミナル案は「読みにくい」で却下、白基調で確定。
  借りたのは**等幅・行番号・プロンプト・diff の4つだけ**で、地は白のまま。
  **質感で真似ず、語彙だけ借りる。**
- **このページ自体を生成物として見せない**（自己言及は 003 で却下）。
  題材は顧客の経費申請で、このサイトの作り方は一度も出さない
- AI の口調にユーモアを混ぜない／生成を失敗させない／極端な値にツッコまない
- **自動で流さない。**開いた瞬間に作業画面が動くと、注文どおりのサイトに見えない。
  キー（Enter / Space）を奪うのも、作業画面を開いたあとだけ
- 色だけに意味を持たせない（diff は記号 `+ -` と色帯の両方）
- 事例が無いことを隠さない（G と同じ一文）

## G と同じ素材を使っている

経費申請／不在のとき・上に上げる額・出したあとの取り下げ／「聞いて集めても出てこない」。
**案が3本並ぶので、素材を変えると比べられなくなる。**
題材を替えるときは3本まとめて替えること。
