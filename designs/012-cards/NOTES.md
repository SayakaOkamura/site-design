## この案が言っていること

**難解さを先に置いて、畳むのはそのあと。**
読みにくい壁を見せてから一枚にまとめるという順番そのものが、主張になっている。

ついでに、これは**会社の主張とも重なる**——
散らばって読めない状態を、決められる形にまとめる。それがこの会社の仕事の話でもある。
だから**この動き自体が、サービスの説明になっている**（011 のデモと同じ構え）。

## 章

```
企業理念        1063 字 / 48 行
サービス        1118 字 / 48 行
上流工程中心とは  951 字 / 45 行     ← 公式には無い章。主張の中核なので立てた
会社概要         557 字 / 29 行     ← ここだけ事実なので短い
```

**膨らませたのは考え方のほうだけ。**
公式に出ている言葉（理念の四段落、サービスの四項目、会社概要）を土台に、
**その言い分を延ばした**。

**実績・数字・取引先・導入事例のような事実は一つも作っていない。**
他人の会社の話を書く場所なので、盛るなら**意見**を盛る。
「上流工程中心とは」の章は全部こちらの書き足しだが、
書いてあるのは**やり方についての意見**であって、やった実績ではない。

## 作り

| | |
| **壁** | 等幅（MS Gothic）・一本の流れ・両端そろえ・`--dim`。三文ごとに一段沈める——**むらが無いと壁に見えない** |
| **印** | 章の頭（左上）に題と並べて。`pulse` で発光。押すところなので、**章の中で唯一明るい** |
| **収束した文** | **白い面は捨てた。**黒地のまま、字が**頭から一字ずつ定まる**。定まる前の字は**その章の壁から借りる**——読めないのではなく「まだ decode できていない」に見せる |
| **畳み方** | 行を**外から内へ**順に消す。端から順だと「上から流れた」になって、集まった感じにならない |

**読みやすさのつまみは `--dim` と `--dim2` の二行だけ。**明るくすればいくらでも読める。

### 踏んだところ

| | |
| **カードの空白が居座った** | `opacity:0` で隠していたので、壁の下に**カード一枚ぶんの空き**が出ていた。`display:none` にして、出すときは **JS で先に置いてから** `.on`（`display` は動かせないので、置いた直後に一度レイアウトを取る） |
| **畳むのが見えない** | 高さと字を同時に動かすと、**枠が縮むほうが速くて**字が消える様子が見えない。高さの動きを **0.22 秒遅らせる** |
| **`max-height:auto` は動かない** | 畳む前に**いまの高さを数字で押さえる**（`scrollHeight`）。011 でも同じところを踏んでいる |

## 組み直した（同じ日）

本人：「**二段にすらしなくていいよ。**あと、できれば**もっと文字でみちみち**にしてほしい。
**教科書の章はじめ**とか、**左上の章タイトルと、それを囲むように文字が配置されてる**でしょ。
あんな感じ」→「**行数減ってもいいから**」。

```
前                          いま
二段組・行ごとに改行          一本の流れ・両端そろえ
題は本文の上、印は右上         題と印を一塊にして**左上に浮かせる**
                            本文は**そのまわりを回る**
```

- **段に切らない。**段に切ると隙間が一本できて、そのぶん「みちみち」でなくなる
- **改行では切らない。**空行で段落に割って、段落の中は一続きに。字間 -0.01em、行間 1.62
- **畳む単位は「文」。**行は幅で決まるので掴めないが、**文（。）なら掴める**

### 隙間は、箱の余りだった

本人：「**今ある隙間詰めていい。タイトルと文章の**」。
余白の数字を削る前に、**箱そのものが中身より広かった。**
幅を決め打ちしていたので、**題より広いぶんがそのまま隙間**になっていた。
→ **幅の決め打ちをやめる。**浮かせた箱は中身に縮む。
題が長い章は二行に折り返してよい——**折り返すほうが、空きを抱えているより詰まって見える**

### 踏んだところ：`overflow:hidden` が回り込みを殺す

畳むために `.raw` に `overflow:hidden` を付けていたら、**文字が章の頭に回り込まなかった。**
`overflow` が `visible` 以外だと**新しい整形文脈**ができて、
箱ごと横へ避けてしまう（行が避けるのではなく）。

→ **外した。**畳むときにはみ出すぶんは、そのころには字が透明になっているので見えない。
`pointer-events` だけ切っておく。

### カードを 009 に寄せた（同じ日）

本人：「**カードっぽくはないな、今。009 でやってたみたいなカードにできる？**」。

前の形は**枠線で囲った板**だった。009 の要は
**「線は一本も引かない。面と影で立てる」**（009 の書き置きにそう残っている）。

```
前                        いま
暗い面・緑の枠線・左に縦線   白い面・角丸 10px・線なし
緑の字                     濃い字＋緑は印だけ
```

- **白い面。**壁が緑の暗がりなので、**白が出た瞬間に「別のもの」になる**——
  読みやすくなったことが、色で分かる
- **黒地では影が効かない**（暗い上に暗い影を落としても出ない）。立つのは**面の明るさそのもの**。
  影は縁をほんの少し沈ませるためだけ
- 字組も 009 から——**題が太く、下に添えの行**。添えの頭の「—」だけ緑
- **走査線の上に出す**（`z-index:10` ＞ 走査線の 9）。
  下に置くと白い面に縞がかかって、**せっかく別の世界にしたものが同じ画面の中に戻る**

#### 出かたは弱めた（手本と落差があったので）

本人：「**タイトルの変形の形と他のが違いすぎてびっくりしそう**」。

先頭（手本）で教えているのは「**字が消える**」だけ。
章ではそこに**白い板が出てくる**ので、押した先が**初見**になる。

三つ出して、本人は **2（章の出かたを弱める）** を取った。
（1 は先頭もカードにする＝手本と同じ動きにする。3 はこのまま）

```
前                              いま
14px 下から跳ね上がる             5px。**その場で浮かび上がるだけ**
0.985 から拡大                   拡大しない
0.5 秒                          0.78 秒
影 0 18px 44px / .55            0 7px 18px / .38
```

- **縮めていたぶん、左端が壁と 7px ずれていた。**拡大をやめたら揃った
- **影は落とすためではなく、縁を沈ませるため。**浮いて見えるほど強いと、
  影そのものが「飛んできた」になる
- **白は残す**（本人も承知のうえで 2 を選んでいる）。
  縮むのは**落差**であって、白くなること自体は変えていない

### 気づかせる。ただし言葉にしない（同じ日）

こちらから「**アイコンを押すことに気づかないと思う**」と出したところ、
本人：「**言葉にはしたくないけど気付かせたい。パッと見たときにえ！？ってなってほしい。**
これあれだな、最初の**会社名だけギリギリわかる**ようにしておいて、
**会社名の周りについてる文字とかを綺麗にまとめるチュートリアル**的なものが必要かな」。

**先頭で一度だけ、ひとりでにやって見せる。**

```
開く          社名が字に埋もれている（社名だけ少し明るい＝ギリギリわかる）
1.7 秒        印が一度だけ強く光る
1.95 秒       まわりの字が集まって消え、社名だけが残って明るくなる
以降          章の印は「押すとあれが起きるもの」に見える
```

- **案内文は消した。**これが手本なので、言葉は要らない
- 印は**章のものと同じ形**。同じ形が同じことをする、と一度で教わる
- **押せば何度でも見られる**（気づいた人が確かめられるように）
- 動きを止める設定のときは、**畳んだ状態で始める**（見せる動きが無いので、読める形を出す）

#### 手本は、最後までやってしまわない

本人：「**勝手に閉じられるとわからん**」。

**ひとりでに畳みきるのをやめた。**
畳み終わった状態だけを見せられても、**自分が押したから起きたのか分からない**——
むしろ「勝手に動く画面」になって、印と結びつかない。

```
前                          いま
2.0 秒で社名がひとりでに     2.2 秒に**一度だけ身じろぎ**する
畳まれ、そのまま終わる       　印が強く光り、まわりの字が 0.62 秒だけ薄れて、戻る
                            **最後までやらない。**畳むのは押した人
```

- **身じろぎは途中で戻る。**「ここで何か起きる」とだけ言って、**結果は渡さない**
- **印に指を乗せると、まわりの字が薄れる**（章の印も同じ）。
  押す前に**因果が見える**ので、言葉で説明しなくていい
- 薄れるのは 0.4 まで。**消さない**——消すと畳んだのと同じになってしまう

#### 一つだけ、言葉で言う

本人：「**チュートリアルとして、ここをクリックみたいなやつをタイトルにだけつけちゃってもいい**」。

先頭の印の横に **「◀ ここを押す」**。**先頭だけ。章には付けない。**
一度教われば、**同じ形は同じことをする**と分かる——章にも並べると、
手本ではなく**注意書きだらけの画面**になる。

- **一度押したら消える**（戻しても出さない。もう教わっている）
- 壁の上に出すので**地の色を敷く**。字の上に字を重ねると読めない
- 明滅は **1 → 0.55 → 1**。0 から上げると、動きが走らない場で**出ないまま**終わる
- ついでに、**先頭の印が Enter で効いていなかった**のを直した
  （章の印用の処理を通っていて、章に属さないこの印では何も起きなかった）

#### 埋もれさせる字は、会社の言葉から取る

意味のない記号を敷くと「**壊れている画面**」に見えて、**え！？が不安のほうに倒れる。**
上流工程／夢中／権限／御成門……と、この会社が実際に使う語を散らしてある。

**最初は同じ語ばかり並んだ。**乱数の**下の桁**を使っていたのが原因（周期が短い）。
上の桁を取ると散る。四十三種類まで増えた。

### カードを捨てた（同じ日）

出かたを弱めたあと、本人：「**なんかいっそもう少しマトリックスっぽくするか**」
→（こちらが色や背景の案を出したので）「**いや、文字の現れ方の話やね、いっそカードを捨てるか**」。

**白い面・角丸・影・角ゴシック——別の世界に移す作りを全部やめた。**
黒地のまま、**壁があった同じ場所で、字がその場で読める形に収束する。**

これで**先頭の手本と章がまったく同じ動き**になる。
（手本＝字が消えて社名が明るくなる。章＝字が消えて要点が明るくなる）
落差をどう縮めるかを二度いじったが、**落差の元はカードそのものだった。**

```
白いカード（前）                 収束した文（いま）
白い面・角丸・影                 面も枠も影も無し
角ゴシック・濃い字                壁と同じ等幅・緑
走査線の上に出す                  走査線の下。**同じ画面の中に戻す**
clear:both で下に置く            clear を外す。**章の頭に回り込む**
ふわっと現れる                    **頭から一字ずつ定まる**
```

#### 定まる前の字は、その章の壁から借りる

よその記号を敷くと「**壊れた画面**」になる。同じ文の字を使うと
「**まだ decode できていない**」に見える——先頭の埋もれた社名と同じ理屈。

- **字数は変えない。**入れ替えるだけなので、行が伸び縮みしない
- **半角のところには半角を差す。**全角を混ぜると、定まるたびに行が伸び縮みする
- 戻したら**読める形に戻しておく**（次に開いたとき、途中の字が残らないように）
- 動きを止める設定のときは、**収束させずにそのまま出す**

#### 化けるのは、いつも一行だけ

本人：「**モーションがちょっと読みにくいな、それやるなら上から下の方がいいかも**」。

はじめは**全部の行がいっぺんに**ざわついていた。目の置き場が無く、読めない。

```
前                            いま
全行が同時に化ける              **化けているのは一行だけ**
下の行も化けた字で見えている      上は読める形で止まっている
                              **下はまだ出ていない**（隠すだけで場所は取る）
```

- **まだの行は消さずに隠す。**消すと、定まるたびに下が持ち上がって行が踊る
- 「もどす」も最後まで出さない。**読み終わる前に出口が見えていると、そこに目が行く**

##### 向きは、下だけにする

最初は「一行ずつ」にしただけで、**行の中は左から右へ**定めていた。
本人：「**文字のモーションが左から右に入るでしょ。あれ上から下にしてほしい**」。

左から定めると、**横に走る線**が見える。読む向きと同じなので、
目がそれを追いかけてしまって、かえって落ち着かない。

→ **一行まるごとが同時に定まる。**行の中に向きは無く、向きは**下向きだけ**になる。

- そのために**一字ずつ `span` に分けて、同じ高さの字をひとまとめ**にする。
  行は幅で決まるので、**畳む直前に測る**（窓を細くすると行数が変わる）
- **測るのは読める形のまま。**隠してから測ると行組みが変わりかねない
- **一行あたりの長さは、全体の行数から決める。**固定にすると、
  窓が細くて行数が倍になったときに**待ち時間だけが倍**になる（1.5 秒ぶんを行数で割る）

##### 二度踏んだ：隠したものは、動きが走らないと出てこない

- **「終わったら次」で繋いだら、途中で止まった。**`requestAnimationFrame` が
  走らない場だと、そこから先が**永久に出てこない**——隠してあるので**消えたのと同じ**。
  → **時刻で組む。**化けなくても、時計が来れば読める形で出る。
  011 の「透明度で動きを作らない」と**同じ失敗**（動きに出現を預けた）
- **読める形に直しても、また化けた。**直したあとも古い tick が生きていて、
  次の行と一緒に前の行も書き換わる。→ **行ごとに番号**を持たせて、追い越されたら降りる

#### 面を捨てたら、直せたもの・直したもの

- **回り込めるようになった。**面がある間は `clear:both` で章の頭の下に置くしかなかった。
  面が無いので、**壁とまったく同じ場所・同じ形**で出せる
- `grid` と `flex` をやめた。**新しい整形文脈ができて回り込まなくなる**（`overflow` と同じ罠）
- 箇条の「—」を**絶対位置で置くのをやめた。**回り込むと行だけが右へ逃げて、
  印が左端に取り残される。**字下げ**にすれば印も行と一緒に動く

#### 借りるのは作法まで

黒地・緑・等幅・縦に流れる——ここまでは端末の作法。
**反転した半角カナの字並びそのものは映画の意匠**なので使わない（011 のスライムと同じ線）。

## 011 から持ち込んだ失敗

- **透明度で動きを作らない**——動きが走らない場（裏の窓、動きを止める設定）で
  `from` の値のまま固まって、**出ないまま**になる。大きさか位置で動かす
- **枚数と中身がぶつかったら、枚数のほうを譲る**——文を削って合わせない
- **画面を揺らさない・強く光らせない**——目に障る
- **製品の意匠は借りない**——黒地に緑は端末の作法であって、特定の製品の見た目ではない
