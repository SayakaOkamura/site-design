散らばって読めない状態を、決められる形にまとめる。それがこの会社の仕事の話でもある。

## 作り

| | |
| **壁** | 等幅（MS Gothic）・一本の流れ・両端そろえ・`--dim`。三文ごとに一段沈める——**むらが無いと壁に見えない** |
| **印** | 章の頭（左上）に題と並べて。`pulse` で発光。押すところなので、**章の中で唯一明るい** |
| **収束した文** | **白い面は捨てた。**黒地のまま、要点が**一行ずつ上から浮かぶ**（色だけが動く）。字を化けさせるのは**やめた**——震えて読みにくい |
| **畳み方** | 行を**外から内へ**順に消す。端から順だと「上から流れた」になって、集まった感じにならない |

**読みやすさのつまみは `--dim` と `--dim2` の二行だけ。**明るくすればいくらでも読める。

### 踏んだところ

| | |

## 組み直した（同じ日）

本人：「**二段にすらしなくていいよ。**あと、できれば**もっと文字でみちみち**にしてほしい。
**教科書の章はじめ**とか、**左上の章タイトルと、それを囲むように文字が配置されてる**でしょ。
あんな感じ」→「**行数減ってもいいから**」。

```
前                          いま
二段組・行ごとに改行          一本の流れ・両端そろえ
題は本文の上、印は右上         題と印を一塊にして**左上に浮かせる**
                            本文は**そのまわりを回る**
```

- **段に切らない。**段に切ると隙間が一本できて、そのぶん「みちみち」でなくなる
- **改行では切らない。**空行で段落に割って、段落の中は一続きに。字間 -0.01em、行間 1.62
- **畳む単位は「文」。**行は幅で決まるので掴めないが、**文（。）なら掴める**

### 隙間は、箱の余りだった

本人：「**今ある隙間詰めていい。タイトルと文章の**」。
余白の数字を削る前に、**箱そのものが中身より広かった。**
幅を決め打ちしていたので、**題より広いぶんがそのまま隙間**になっていた。
→ **幅の決め打ちをやめる。**浮かせた箱は中身に縮む。
題が長い章は二行に折り返してよい——**折り返すほうが、空きを抱えているより詰まって見える**

### 踏んだところ：`overflow:hidden` が回り込みを殺す

畳むために `.raw` に `overflow:hidden` を付けていたら、**文字が章の頭に回り込まなかった。**
`overflow` が `visible` 以外だと**新しい整形文脈**ができて、
箱ごと横へ避けてしまう（行が避けるのではなく）。

→ **外した。**畳むときにはみ出すぶんは、そのころには字が透明になっているので見えない。
`pointer-events` だけ切っておく。

### カードを捨てた（同じ日）

→（こちらが色や背景の案を出したので）「**いや、文字の現れ方の話やね、いっそカードを捨てるか**」。

**白い面・角丸・影・角ゴシック——別の世界に移す作りを全部やめた。**
黒地のまま、**壁があった同じ場所で、字がその場で読める形に収束する。**

これで**先頭の手本と章がまったく同じ動き**になる。
（手本＝字が消えて社名が明るくなる。章＝字が消えて要点が明るくなる）
落差をどう縮めるかを二度いじったが、**落差の元はカードそのものだった。**

```
白いカード（前）                 収束した文（いま）
白い面・角丸・影                 面も枠も影も無し
角ゴシック・濃い字                壁と同じ等幅・緑
走査線の上に出す                  走査線の下。**同じ画面の中に戻す**
clear:both で下に置く            clear を外す。**章の頭に回り込む**
ふわっと現れる                    **頭から一字ずつ定まる**
```

#### 化けさせるのは、やめた

本人：「**これモーション自体が列で揺れてるからそう見えるのか。単純に読みにくいかも**」。

一字ずつ毎こま別の字に入れ替えていたので、**行がガタガタ震えていた。**
**震えの正体は「読めない字が動いている」こと**なので、
回数を落としても（二〜三回にしても）読みにくさの質は変わらない。

→ **化けるのをやめた。行が上から順に点いていくだけ。**
押したことと結果の繋がりは、これで足りる。

三つ出して、本人は **1（化けるのをやめる）** を取った。
（2 は化ける回数を落とす。3 は行の頭の数字だけ化けさせる）

##### 出る／出ないの二値は、硬い

化けるのをやめたら、今度は本人：「**あーでも硬いな**」。
行が**カチカチと入れ替わる**——出ていないか、出ているか、の二つしかなかった。

→ **暗がりから浮かせる。色だけを動かす。**
位置も字も変えないので、**震えは戻らない**。

- 隠すのも「見えない」ではなく**透明な字**にしておく（場所は取ったまま）
- **透明な字でも影は出る。**消しておかないと、**光の染みだけが先に見える**
- 浮かぶのに 0.55 秒かかるので、行の間隔はそれより短くてよい——
  **重なったほうが一続きの流れ**に見える。間を空けると、また硬くなる
- 行き先は**普通の色**なので、動きが走らない場でも**そのまま読める形で出る**
  （透明度で動きを作らないのと同じ構え）

以下は**やってみて捨てた作り**。考え方は残しておく——

##### 定まる前の字は、その章の壁から借りていた

よその記号を敷くと「**壊れた画面**」になる。同じ文の字を使うと
「**まだ decode できていない**」に見える——先頭の埋もれた社名と同じ理屈。

- **字数は変えない。**入れ替えるだけなので、行が伸び縮みしない
- **半角のところには半角を差す。**全角を混ぜると、定まるたびに行が伸び縮みする

**残したのは、一字ずつ `span` に分ける作り。**行ごとにまとめて出すのに要る。
戻したら読める形に戻しておくこと、動きを止める設定では順番待ちをさせないことも、そのまま。

#### 化けるのは、いつも一行だけ

本人：「**モーションがちょっと読みにくいな、それやるなら上から下の方がいいかも**」。

はじめは**全部の行がいっぺんに**ざわついていた。目の置き場が無く、読めない。

```
前                            いま
全行が同時に化ける              **化けているのは一行だけ**
下の行も化けた字で見えている      上は読める形で止まっている
                              **下はまだ出ていない**（隠すだけで場所は取る）
```

- **まだの行は消さずに隠す。**消すと、定まるたびに下が持ち上がって行が踊る
- 「もどす」も最後まで出さない。**読み終わる前に出口が見えていると、そこに目が行く**

##### 向きは、下だけにする

最初は「一行ずつ」にしただけで、**行の中は左から右へ**定めていた。
本人：「**文字のモーションが左から右に入るでしょ。あれ上から下にしてほしい**」。

左から定めると、**横に走る線**が見える。読む向きと同じなので、
目がそれを追いかけてしまって、かえって落ち着かない。

→ **一行まるごとが同時に出る。**行の中に向きは無く、向きは**下向きだけ**になる。
（このあと化けること自体をやめたが、**行ごとにまとめて出す作りはここで要った**）

- そのために**一字ずつ `span` に分けて、同じ高さの字をひとまとめ**にする。
  行は幅で決まるので、**畳む直前に測る**（窓を細くすると行数が変わる）
- **測るのは読める形のまま。**隠してから測ると行組みが変わりかねない
- **一行あたりの長さは、全体の行数から決める。**固定にすると、
  窓が細くて行数が倍になったときに**待ち時間だけが倍**になる（1.5 秒ぶんを行数で割る）

##### 二度踏んだ：隠したものは、動きが走らないと出てこない

- **「終わったら次」で繋いだら、途中で止まった。**`requestAnimationFrame` が
  走らない場だと、そこから先が**永久に出てこない**——隠してあるので**消えたのと同じ**。
  → **時刻で組む。**化けなくても、時計が来れば読める形で出る。
  011 の「透明度で動きを作らない」と**同じ失敗**（動きに出現を預けた）
- **読める形に直しても、また化けた。**直したあとも古い tick が生きていて、
  次の行と一緒に前の行も書き換わる。→ **行ごとに番号**を持たせて、追い越されたら降りる

#### 面を捨てたら、直せたもの・直したもの

- **回り込めるようになった。**面がある間は `clear:both` で章の頭の下に置くしかなかった。
  面が無いので、**壁とまったく同じ場所・同じ形**で出せる
- `grid` と `flex` をやめた。**新しい整形文脈ができて回り込まなくなる**（`overflow` と同じ罠）
- 箇条の「—」を**絶対位置で置くのをやめた。**回り込むと行だけが右へ逃げて、
  印が左端に取り残される。**字下げ**にすれば印も行と一緒に動く

#### 借りるのは作法まで

### 何が起きていたか

この案の本体は**落差**——読めない壁があって、押すと読める形になる。
9/15 に**その落差を三度削っていた。**

```

出る／出ないの二値   → 硬い                 → 色だけ動かす
白いカード         → 手本と落差がありすぎる   → 捨てた
```

**一つずつは全部正しい。**どれも実際に読みにくかったり、びっくりする形だった。
ただ三つ重なって、**両端が真ん中に寄った。**

### 削った落差は、可読性を払わない場所に置き直す


```
夢中─┬─　「遊ぶように働く」は楽をすることではなく、…
    │

    │
    ├─　その四つを決めているのは現場ではなく経営。…
    │
    └─　語ることと作ることを同じ会社に置いて、…
```

### 線は字で引く

`├ └ ─ │` は**等幅なので桁に乗る。**枠線（`border`）で引くと
**章の頭に回り込めない**——`border` は箱に付くので、浮かせた頭の下に潜る
（行だけが float を避けるのと同じ理屈。9/15 に `overflow:hidden` で一度踏んでいる）。

字で引けば**インラインなので、行と一緒に避ける。**

### 桁は `ch` で数える（`em` ではない）

全角の字は **16px**、`1em` は **15px**。`em` でぶら下げを組むと
**一行ごとに 6px ずつずれた。**半角 `0` 一つが `1ch` なので、全角一つ＝**`2ch`**。
`\u3000` も `─` も `├` も `│` も同じ幅だった（実測）。

### 幹は二重に付ける

`cells()` が**中身を作り直す**（一字ずつ `<span>` に割る）ので、入れ子の印は残らない。
→ 要素に**何桁目までが幹か**（`data-rt`）を持たせて、出来上がった桁に付け直す。

ただし**動きを止める設定では `cells()` が走らない。**
そのままだと、そこだけ幹が立たないまま出た。→ **`<span class="rt">` でも包んでおく。**
（実測：普通 `rgb(185,255,210)` ／ 止める設定でも同じ）

### 枝と枝のあいだに一本立てる

印だけだと箇条書きに見える。**`│` が通って初めて「一本から分かれた」**に見えた。
空の行（`li.sp`）を挟んで、行間だけ詰める。

### 細い窓：ぶら下げは幹の長さで数えない

一行 20 字ほどしか無いので、幹（2〜3 字）＋腕（3 字）を毎行あけると
**一行の三分の一が空白**になり、一項目が四行に伸びた（320×568 で実測）。
→ **腕の三桁だけぶら下げる**（`6ch`）。一行目は幹から始まるので負の `text-indent` で引き戻す。

```

320×568  84〜98px → **42px**    3〜4 行 → **3 行**
390×844  84〜98px → **42px**    3 行   → **2〜3 行**
```
